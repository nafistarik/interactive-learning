## PART 1 — PRODUCT VISION

The long-term product is a visual learning platform for Machine Learning, Deep Learning,
Transformers, Reinforcement Learning and Agentic AI. MVP 1 builds one module only:

**Arrays, Vectorization & Broadcasting**

Learners do not just read how an operation works. They write real Python, run it, and
watch what happens to the data:

**Understand → Experiment → Write code → Execute → Visualize → Practice → Validate**

The visualization driven by real execution is the product's differentiator. Prioritise the
quality of this one learning experience over the number of features.
