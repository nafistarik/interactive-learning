## HOW TO WORK (read first)

1. Build the MVP **milestone by milestone** (Part 0). Finish one milestone end to end,
   run the checks in Part 14, then **stop and report** using the milestone report in
   Part 17. Wait for the user to say "continue" before starting the next milestone.
2. Inside a milestone, make ordinary design and coding decisions yourself. Do not stop
   to ask about them. Write every assumption you made into the milestone report.
3. Never fake anything: no hard-coded execution output, no animation that is not driven
   by real execution data, no placeholder interaction presented as working. If a
   requirement cannot be met, build the closest honest version and say so in the report.
4. Never claim a feature works, or a test passed, unless you ran it.
