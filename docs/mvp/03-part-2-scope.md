## PART 2 — SCOPE

### In scope

Dashboard · Module Overview · lesson navigation · Theory with interactive demos and
knowledge checks · Monaco Python editor · Pyodide/NumPy execution in a Web Worker ·
statement-level stepping · array, shape, indexing, element-wise and broadcasting
visualizations · execution timeline · variable inspector · visual error explanation ·
four exercises with validation · XP and stars · progress tracking · dark/light theme ·
LocalStorage persistence.

### Out of scope — do not build

Backend APIs, database, authentication, registration, admin panel, CMS, cloud sync,
AI tutor or any LLM call, PyTorch, multi-user features, desktop app, Tauri/Rust,
**Three.js or any WebGL 3D rendering**, and any module other than this one.

The MVP is a self-contained frontend application. Python runs only in the browser.
