# Roadmap

What the whole product is, how it is built, and what ships next.

**Product:** a visual learning platform for Machine Learning, Deep Learning,
Transformers, Reinforcement Learning and Agentic AI. Learners write real Python, run
it, step through it, and watch the data change — driven by the actual execution, never
by canned animation.
