# Open decisions

Decisions the plan cannot make on its own. Each says what it blocks and a default if
nobody decides.

| # | Decision | Blocks | Default if undecided |
|---|---|---|---|
| 1 | **The full curriculum.** The original plan mentions 25 core modules, 26 side quests and 6 boss arenas, but the list is not written down in the repo. | Module names and order in R2/R3 | The proposals in the release plan |
| 2 | **Phase names.** Phase 0 = "NumPy for ML" with Arrays as Module 0.1? | Dashboard roadmap, URLs in R2 | Yes |
| 3 | **Where to launch.** Hosting, domain, who the first learners are. | R1.1 | Vercel static hosting; 5–8 known learners |
| 4 | **Language.** When does Bangla content come, and for which modules first? | Content workload per release | English first, Bangla after Phase 0 |
| 5 | **PyTorch route.** Server sandbox, desktop with local Python, or NumPy-only foundations. | R5 | Decide at the end of R3; NumPy-only until then |
| 6 | **Accounts.** Needed at all, and when? | R4 | Only if learners return across days/devices |
| 7 | **AI.** Which model/provider, cost limit, and what the AI may do (hints only, never answers?). | AI hints, Agentic AI phase | Not before R4 |
| 8 | **Gamification scope.** Levels, streak, side quests, boss arenas. | UI scope from R2 on | XP + stars only until the core path exists |
